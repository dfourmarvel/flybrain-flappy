I suck at Flappy Bird, so I had a fly play for me

A simulated 2,493-neuron circuit from a real fruit-fly connectome (wiring frozen) sits between the game and the flap. A fitted interface does the game logic; the circuit relays it.

Live: this runs the same circuit and the same fitted interface in your browser, on a fresh endless level. It will not match the recorded run spike for spike, because small numerical differences grow chaotically; it is checked against the Python simulator on average rates and scores. The fly plays until it crashes.

Race: you and the live fly play the same fresh endless level, on one canvas. The fly (cyan) runs in this browser, not from a recording. Space, click or tap flaps for you (amber) only.

How this works

The connectome — the wiring diagram of a real fruit fly's brain, down to individual synapses — is never changed. A small sub-circuit around the fly's visual looming-detection and escape pathways is simulated from that measured wiring. The only thing that was fitted to this game is a thin interface: how the pipe's distance and the bird's height relative to the gap turn into simulated visual input, and how a spike-count readout turns into a flap decision. The brain did not learn Flappy Bird; the interface around it was fitted.

Looming neurons respond to an object growing larger in the visual field — here, an oncoming pipe. Escape neurons, including the giant fiber DNp01, are the fly's fast last-resort motor command; in this demo that command is read out as the flap decision.

The scores and run statistics on this page come from the offline runs, on levels capped at 1,500 frames. Live and race levels have no frame cap, so a long-lived fly keeps scoring until it crashes. Each level number is a random seed: the same number gives the same pipes.
