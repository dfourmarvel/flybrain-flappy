How this works

The connectome — the wiring diagram of a real fruit fly's brain, down to individual synapses — is never changed. A small sub-circuit around the fly's visual looming-detection and escape pathways runs exactly as measured. The only thing that was fitted to this game is a thin interface: how the game's pixels turn into simulated visual input, and how a spike-count readout turns into a flap decision. The brain itself did not learn Flappy Bird — the interface around it did.

Looming neurons respond to an object growing larger in the visual field — here, an oncoming pipe. Escape neurons, including the giant fiber DNp01, are the fly's fast last-resort motor command; in this demo that command is read out as the flap decision.

Physics verified against the Python engine: this page's game physics were checked frame-by-frame against the recorded Python run (node docs-site/parity.test.mjs) and match exactly.
