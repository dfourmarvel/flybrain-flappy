I suck at Flappy Bird, so I had a fly play for me

A simulated circuit from a real fruit-fly connectome (wiring frozen) sits between the game and the flap. A fitted interface does the game logic; the circuit relays it.

Live: the same circuit and fitted interface, running in your browser on a fresh level until the fly crashes. Not spike-for-spike identical to the recorded run; checked against the Python simulator on average rates and scores.

Race: you (red) and the live fly (yellow) on the same fresh level. Space, click or tap flaps for you only.

This is a replay of one real recorded run, not a live simulation. The brain ran once, offline, in Python; what you see is that run, frame by frame.

How this works

Frozen

The connectome: the wiring diagram of a real fruit fly's brain, down to individual synapses. It is never changed. A sub-circuit around the fly's looming-detection and escape pathways is simulated from that measured wiring (the limitations list what is approximated).

Fitted

A thin interface: how the pipe's distance and the bird's height relative to the gap become input to the looming neurons, and how the escape neurons' spikes become a flap. The brain did not learn Flappy Bird; the interface around it was fitted.

What the brain is doing

From the offline runs, on levels capped at 1,500 frames.

The interface already tells the circuit whether the gap is above or below, by which side's looming neurons it drives. The circuit's job is to carry that left/right signal to the escape neurons while keeping the two sides largely separate.

A one-line rule using the same signal, with no brain at all, scores , so the circuit is not solving the game. Shuffled versions of the same wiring lose that left/right separation and are also much more active overall; all of them scored or less. Which of those differences makes them fail was not tested (details).

Looming neurons
Respond to an object growing larger in the visual field: here, an oncoming pipe.
Escape neurons
Including the giant fiber DNp01, the fly's fast last-resort motor command. In this demo that command is read out as the flap decision.
Levels
The scores and run statistics on this page come from the offline runs, on levels capped at 1,500 frames. Live and race levels have no frame cap, so a long-lived fly keeps scoring until it crashes. Each level number is a random seed: the same number gives the same pipes.

Recorded run

Physics verified against the Python engine: the game physics were checked frame by frame against the recorded Python run (node docs-site/parity.test.mjs) and match exactly. The live brain is checked on average rates and scores, not spike for spike (node docs-site/live.test.mjs).
